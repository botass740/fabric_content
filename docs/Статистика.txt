Как нашёл channel_id

Playwright зашёл на dzen.ru, в HTML всех ссылок была одна /id/69b6a72cdbc5135fe5998d4f (это ID нашего пользователя). Но это был юзер-аккаунт, а не канал. Дальше — dzen_state.json не содержит slug, поэтому я открыл реальный URL нашей опубликованной статьи через requests+куки (/a/aoBNu9tQ_mYuMNiZ) и в её HTML нашёл from_parent_id=-1628563791541442463 и channel_id=637b09c7e1c5d415d437e6ab. После этого запрос https://dzen.ru/api/v3/launcher/channel?channel_id=637b09c7e1c5d415d437e6ab&limit=200 вернул полную выгрузку (335 КБ JSON, 10 страниц, 163 статьи).

Что НЕ удалось

- Страница статистики канала /profile/editor/<id>/statistics и /api/v3/launcher/channel?id=... — оба 404. Скорее всего, статистика канала для владельца доступна только в веб-интерфейсе студии (dzen.ru/profile/editor/new/...), куда мы не зашли (он требует авторизованного persistent profile, а Playwright-сессия не авторизовалась — zencookie длина 19, «Войти» на главной).
- Likes/comments на конкретных статьях — взяты из HTML страниц (как в прошлый раз). Точно так же, как для 560 чужих статей в data/research.db.
- Подписчики/просмотры канала по дням — API export не даёт разбивки по дням, только агрегат на момент выгрузки.
