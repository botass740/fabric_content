> **Для ИИ-агента, который будет строить разнообразный контент-план.**
> Подготовлено: 2026-09-07. Источники:
> - 60 статей vzoprodengi (`data/analysis_source/vz_*.txt`) — эталон
> - 5 наших опубликованных статей (`data/analysis_source/our_articles.txt`, id 28, 29, 30, 31, 40)
> - 10 неопубликованных: 1 approved (#26), 6 generated (#32-37), 3 rejected (#37-39)
> - Готовый разбор vzoprodengi (`data/vzoprodengi_analysis.md`)
> - Метрики (`data/research/analysis/comparison.json`)

## TL;DR — главный вывод

Все наши статьи (как опубликованные, так и сгенерированные, и rejected) рассказывают **одну и ту же историю** с минимальными вариациями:

> **«Я (анонимный, нестарый, без имени/города) купил/потратил/накопил Х, а потом понял/постеснялся/испугался/решил Y. Вот что я вынес из этого.»**

Это **поток сознания от первого лица**, без конкретного героя, без города, без возраста, без профессии. **5–10 вариаций одной и той же сюжетной формулы.** Когда читатель видит второй заголовок «Я купил X за Y, а теперь Z», он уже знает финал и скучает. Когда видит третий — уходит.

У vzoprodengi (наш эталон) **другая** формула: **журналистский репортаж о другом человеке**. Каждая статья — конкретный герой с именем, возрастом, городом, профессией, пенсией до рубля, и уникальная бытовая ситуация. Эти истории не повторяются — потому что повторять нечего. Каждая ситуация рождается из жизни одного конкретного человека.

**Корень однообразия:** модель упорно выдаёт «я-исповедника», хотя промт `article_prompt.txt` явно требует 3-е лицо + репортаж о другом человеке + паспорт героя (имя/город/профессия/сумма) + источник истории.

**Паттерн сюжета один из двух:**
- **A) «Я купил/потратил X → постеснялся/пожалел/испугался → рефлексия»** — про статусные покупки, импульс, скидки, кредиты на ерунду.
- **B) «Я отказал/попросил/дал в долг → отношение изменилось → мораль»** — про границы с роднёй, про отказ.

**Обе формулы строятся от первого лица. Обе заканчиваются внутренним монологом рассказчика.**

### 1.2 Что НЕ меняется между статьями

| Признак | Во всех наших | У vzoprodengi |
|---|---|---|
| Рассказчик | анонимный «я» | названный по имени «Макс», либо подразумевается |
| Герой статьи | сам рассказчик | **другой человек** (мать, соседка, дед, свекровь, дочь) |
| Имя героя | нет | есть (Мария Степановна, тётя Галя, Виктор Петрович…) |
| Возраст героя | не указан | конкретный (45, 55, 70, 79…) |
| Город | не указан | назван (Саранск, Казань, Таганрог, Пермь, Петрозаводск…) |
| Профессия | не указана | конкретная («42 года учительницей нач. классов») |
| Пенсия/доход | не указан | точная сумма (19 400, 23 400, 24 800, 21 900) |
| Источник истории | отсутствует | назван («историю рассказала племянница, моя коллега», «узнал от двоюродной сестры») |
| Сюжетный конфликт | внутренний (стыд/тревога) | межличностный (мать-сын, соседка-сосед, покупатель-продавец) |
| Деньги | психологическая категория | измеритель отношений + арифметика судьбы |
| Финал | афоризм/самопознание | 2 вопроса читателю + призыв к комменту + бренд-строка «Больше интересного у нас в канале Макс.» |
| Длина | медиана 1653 (последние 6) vs 4638 (published) | 685–1007 слов, медиана 838 |
| Жанр | поток сознания | журналистский репортаж с подзаголовками-секциями |

### 1.3 Что меняется — только декорации

Чтобы скрыть однообразие сюжета, модель меняет поверхностные атрибуты:

- **Предмет покупки:** часы → куртка → наушники → браслет для жены → пуховик → чеки.
- **Триггер:** скидка 70% → «чёрный день» → подписки → кнопка «куратор за 490 ₽» → «компенсируем бензин».
- **Семейная роль:** жена-бухгалтер → мать-пенсионерка → сестра-фрилансер → соседка-Лена → одногруппник.

Но **архетип покупателя/копящего/должника — один и тот же**: **молодой/средних лет мужчина в городе-миллионнике, фрилансер или офисный работник, с нестабильным доходом, в отношениях «жена ведёт бюджет»**. В нашей выборке 4 из 5 published и 7 из 10 неопубликованных — именно этот архетип.

## 2. Сравнение с эталоном (vzoprodengi) — в чём РАДИКАЛЬНАЯ разница

| Параметр | vzoprodengi (60 статей) | Наши (15 статей) |
|---|---|---|
| **Точка зрения** | репортёр → о герое | рассказчик → о себе |
| **Главное действующее лицо** | другой человек с паспортом | сам рассказчик без паспорта |

| **Конкретика-арифметика** | «287 рублей за свадьбу», «118 тысяч в конверте», «30 лет ипотеки» | размыто: «куча денег», «нормально» |

## 3. Почему так получается (корневые причины однообразия)

### 3.1 Модель упорно выдаёт «я-рассказчика» вместо «репортёра»

Промт `article_prompt.txt:27-37` явно требует:

> «*Ты пишешь НЕ исповедь рассказчика, а РЕПОРТАЖ о другом человеке. В центре статьи — конкретный герой: имя, возраст, город, профессия, размер пенсии.*»

**Но в 14 из 15 наших статей главный герой — сам рассказчик.** Даже когда модель формально вводит персонажа («Соседка Лена», «Сын Серёжа»), рассказчик остаётся центральной фигурой, а «другой человек» — функцией.

**Гипотеза:** `topic_prompt.txt:29-33` указывает архетип рассказчика, а `article_prompt.txt` хочет репортаж о другом. Это два конкурирующих указания, и модель выбирает то, что проще — сам рассказчик.

### 3.2 Матрица 5 осей не работает на разнообразие

`used_combinations` в `data/app.sqlite3` (n=11):
- **hero**: фрилансер 2, студент 2, муж-«казначей» 2; остальные по 1. **Три архетипа-фаворита дают 55% статей.**
- **emotion**: «тихая злость» 2, «надежда» 2; всё остальное по 1.
- **format**: «разоблачение», «контр-мнение», «дневник трат» по 2; всё остальное по 1.
- **trigger**: МФО 3, ремонт 2; **7 из 15 триггеров вообще не использованы** (подписки, маркетплейсы, ЖКХ, дети, подарки, доставка, здоровье, продукты).
- **hook_type**: «анти-совет» 3, остальные по 1-2.

Взвешенный выбор тем более-менее работает по hero/format/hook, но **модель сюжетно не варьирует** — каждый раз генерирует одну и ту же «я-исповедник + покупка/кредит/долг + стыд + рефлексия».

### 3.3 Темы «Я купил X» и «Я взял кредит» формально запрещены, но модель выдаёт

В `topic_prompt.txt:296-298` явно:
> «*сюжет «купил статусную вещь - стыдно показывать»; сюжет «взял кредит на мечту - теперь жалею»*» — **запрещены**.

Но 9 из 15 наших статей — именно эти сюжеты. Модель нарушает явный запрет.

### 3.4 Knowledge base подсказывает не те кластеры

`topic_clusters.json`:
- investments 17.5%, banking 28.7%, budget 20.4%, stories 35%, macro 36.6%, fraud 3.8%, real_estate 6.6%.

Мы пишем совсем другие темы (МФО 3, ремонт 2, долги родне 1, продукты 1) — KB только шумит в промте, но не помогает.

### 3.5 Длина резко просела у новых статей

- published (n=30): median 4638, min 3459, max 6928
- generated (n=6): **median 1653, min 1309, max 6320**

5 из 6 последних generated **короче целевого коридора 4000-6000** символов. История «обрывается», не успев развиться — отсюда вялые диалоги, нет арифметики, нет поворота, нет финального блока. **Короткий текст = повторение уже сказанного = скука.**

### 3.6 Финальный блок (CTA) часто отсутствует

В vzoprodengi: **58/59** заканчиваются вопросом читателю + «напишите в комментариях» + «Больше интересного у нас в канале Макс.»

В наших: **0/15** имеют полный финальный блок. Только #36 имеет подобие вопроса («…он сам решает, когда вставать» — но это не вопрос читателю). Остальные обрываются на афоризме, «фотографии сцены» или самопознании.

## 6. Что должен делать ИИ-агент при построении контент-плана

### 6.1 Обязательные правила (анти-однообразие)

1. **Запрет «я-исповедника» как главного героя.** Каждая тема должна иметь возможность рассказать её **от третьего лица** о другом человеке с паспортом. Если не получается — тему отбросить.

2. **В каждой теме должен быть конфликт между людьми**, а не только внутри рассказчика. Конкретно: «мать — дочь», «соседка — сосед», «продавец — покупатель», «свекровь — невестка», «внук — дед», «муж — жена».

3. **В каждой теме должно быть движение** — не «я задумался», а «мать пришла / позвонила / уехала / переписала / сказала». Действие, а не рефлексия.

4. **Паспорт героя обязателен** — имя + возраст + город (не Москва) + профессия или пенсия (конкретная сумма) + источник истории.

5. **Одна точная сумма в заголовке обязательна.** Заголовки без цифр не публикуем. «+22% слов в топ-20% статей» (из метрик) — это про конкретику.

6. **Запрещены сюжеты из чёрного списка** (прямо из `topic_prompt.txt:294-301`): «купил статусную вещь — стыдно», «взял кредит на мечту — жалею», абстрактные «как накопить», «5 правил богатства», «я и моя тревога», крипто, ставки, политика, быстрые схемы заработка.

### 6.2 Структура контент-плана на месяц (12 статей)

Распределение для контент-плана на месяц (3 статьи в день × 30 дней = 90 статей; или 1 статья в день × 30 = 30; или недельный план на 4-5 статей). Рекомендация:

**На 30 статей:**
- 8 — семейный конфликт через деньги (рубрика 1)
- 4 — сравнение эпох (рубрика 2)
- 4 — бабушка-банкомат (рубрика 3)
- 3 — мошенничество (рубрика 4)
- 3 — подарки, которые не работают (рубрика 5)
- 2 — доброта без расчёта (рубрика 7)
- 2 — конфликт поколений (рубрика 6)
- 2 — live_triggers: ЖКХ / автосписания / отпуск / налоги (рубрики 9-12)
- 1 — «семья — это не кровь» (рубрика 8)
- 1 — «Сравнение с конкурентом по теме»

**Запрет:** подряд 2 одинаковых сюжета («купил и пожалел», «взял в долг и пожалел»). Между ними минимум 3 статьи других рубрик.

**Запрет:** подряд 2 одинаковых формата (исповедь/исповедь, разбор/разбор). Чередование: репортаж → разбор → репортаж → разбор → репортаж.

**Запрет:** подряд 2 одинаковых хука (вопрос-вопрос-вопрос, цифра-цифра-цифра). Чередование: цифра+контраст → анти-совет → неожиданное наблюдение → правда о… → вопрос-провокация → признание.

### 6.3 Шаблон задания для генерации каждой конкретной темы

```
РУБРИКА: [одна из 12 выше]
ФОРМАТ: [репортаж | разбор | список наблюдений | дневник трат | письмо себе | разговор с другом | разоблачение схемы]
ХУК: [один из 6]
ГЕРОЙ: [имя, возраст 45-75, город не Москва, профессия/пенсия]
ИСТОЧНИК ИСТОРИИ: [племянница, соседка, читательница, мамина знакомая...]
КОНФЛИКТ МЕЖДУ ЛЮДЬМИ: [кто — кто — из-за чего]
ПОВОРОТ: [одно необратимое действие, слово, открытие]
ЦИФРА В ЗАГОЛОВКЕ: [конкретная сумма или срок]
ИСТОЧНИК ЦИФРЫ: [откуда она в статье, из какой сцены]
СВЯЗЬ С LIVE_TRIGGERS: [ЖКХ / подписки / мошенники / отпуск / ...]
```

### 6.4 Проверка готового контент-плана

Каждую тему агент должен проверить по 5 вопросам:

1. Есть ли **конкретный герой** (имя + возраст + город + профессия/сумма)?
2. Есть ли **источник истории** («рассказала племянница»)?
3. Есть ли **конфликт между людьми**, а не только внутри рассказчика?
4. Есть ли **цифра в заголовке** (сумма или срок)?
5. **Не повторяется** ли сюжет с любой из последних 10 опубликованных наших статей?

Если «нет» на любой вопрос — тема отклоняется.

## 7. Итог: однообразие в одной фразе

**Все 15 наших статей — это вариации одной и той же исповеди «я-покупателя/копящего/должника», которую рассказчик ведёт сам о себе. Разные декорации, один и тот же внутренний сюжет, один и тот же финал-рефлексия. vzoprodengi делает противоположное: 60 уникальных историй о 60 разных людях с разными жизнями, объединённых не сюжетом, а формулой «репортёр + паспорт + деньги-как-измеритель-отношений». Нам нужно перейти от первого ко второму — тогда разнообразие возникнет автоматически, потому что разнообразие людей и есть разнообразие историй.**
