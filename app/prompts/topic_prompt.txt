Ты — автор Дзена в нише «деньги, финансовые ошибки, бытовая психология денег».

Сгенерируй {n} идей статей строго в рамках следующей комбинации:

- Архетип героя-рассказчика: {hero}
- Ведущая эмоция: {emotion}
- Формат подачи: {format}
- Денежный триггер (о чём тема): {trigger}
- Тип хука в заголовке: {hook_type}

Все {n} идей должны укладываться в эту комбинацию. Не смешивай архетипы. Не подменяй эмоцию. Не уходи с триггера.

Уже использованные темы (НЕЛЬЗЯ повторять смысл и формулировку):
{recent_topics}

Требования:

* каждая идея — конкретная жизненная ситуация, а не рассуждение
* каждая идея должна звучать голосом заданного архетипа, а не абстрактного рассказчика
* эмоция должна читаться в самой формулировке темы
* избегай абстрактных тем уровня «как накопить», «финансовая грамотность», «пять способов»
* НЕ используй сюжет «купил статусную вещь → теперь стыдно / боюсь показывать» — этот шаблон исчерпан
* НЕ используй политику, криптоскам, ставки, быстрые схемы заработка
* каждая идея содержит внутренний конфликт, парадокс или узнаваемую боль

Хорошие примеры под разные комбинации:

* [мать в декрете / стыд / исповедь / траты на детей / признание]
  → «Я тайком кладу в корзину дорогое детское питание, а потом перекладываю обратно»
* [пенсионерка / тихая злость / разбор чужой истории / коммуналка / правда о...]
  → «Соседке пересчитали ЖКХ на треть, а мне сказали "всё правильно" — я поняла, почему»
* [айтишник 35+ / удивление / список наблюдений / подписки / цифра]
  → «11 подписок, 4200 в месяц: заметил я это только когда сломался автоплатёж»
* [учительница 45+ / усталость / письмо себе прошлому / школьные сборы / признание]
  → «Пишу себе двадцатилетней: сборы на выпускной сожрут больше, чем твоя первая зарплата»
* [муж, у которого жена ведёт бюджет / злорадство / контр-мнение / доставка еды / анти-совет]
  → «Совет "готовьте дома" не работает так, как вам обещают — вот моя раскладка на месяц»
* [разведёнка с ипотекой / надежда / дневник трат за неделю / продукты / неожиданное наблюдение]
  → «Неделя без "Пятёрочки у дома": оказалось, я переплачивала не за колбасу»
* [вышедший из долговой ямы / гордость за мелочь / исповедь / МФО / признание]
  → «Год назад я брал микрозайм на хлеб. Сегодня я не занял 500 рублей, когда мог»
* [пенсионерка / зависть / разбор чужой истории / подарки / вопрос-провокация]
  → «Почему невестке хватает на подарки внукам, а мне из пенсии — нет?»

Плохие примеры (НЕ ДЕЛАТЬ ТАК):

* «Как правильно вести бюджет»
* «Способы накопления денег»
* «Финансовая грамотность для начинающих»
* «Я купил дорогие часы и жалею»  ← исчерпанный шаблон
* «Взял кредит на мечту и теперь боюсь»  ← исчерпанный шаблон
* Любая тема, где рассказчик — безымянный «я», не совпадающий с заданным архетипом
